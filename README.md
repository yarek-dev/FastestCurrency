# Fullstack Bot — Telegram-конвертер валют

Telegram-бот для конвертации валют. Бот принимает сумму и ISO-коды валют в личном чате, получает актуальный курс через CurrencyBeacon или Frankfurter и возвращает результат прямо в ответе на webhook.

## Возможности

- конвертация валют по сообщениям вида `100 EUR USD`;
- сумма по умолчанию — `1`, валюта назначения по умолчанию — `USD`;
- основной источник курсов CurrencyBeacon и автоматический переход на Frankfurter при его недоступности;
- работа только с личными сообщениями Telegram;
- проверка webhook-запросов по секретному токену;
- health-check и структурированные логи Fastify;
- валидация суммы и понятные сообщения об ошибках.

## Стек

- Node.js 24;
- TypeScript 5;
- Fastify 5;
- pnpm 10.

## Требования

- Node.js `24.x`;
- pnpm `10.34.5` или совместимая версия;
- Telegram-бот, созданный через [BotFather](https://t.me/BotFather);
- публичный HTTPS-адрес для приема Telegram webhook.

## Быстрый старт

1. Установите зависимости:

   ```bash
   pnpm install
   ```

2. Создайте `.env` из примера:

   ```bash
   cp .env.example .env
   ```

   В PowerShell:

   ```powershell
   Copy-Item .env.example .env
   ```

3. Заполните как минимум `TELEGRAM_WEBHOOK_SECRET` в `.env`.

4. Запустите приложение в режиме разработки:

   ```bash
   pnpm dev
   ```

5. Проверьте сервер:

   ```bash
   curl http://localhost:3000/health
   ```

   Ожидаемый ответ:

   ```json
   {"status":"ok"}
   ```

По умолчанию сервер доступен на порту `3000`. Изменить порт можно переменной `PORT`.

## Переменные окружения

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `TELEGRAM_WEBHOOK_SECRET` | Да | Секрет для проверки заголовка `X-Telegram-Bot-Api-Secret-Token`. Telegram допускает символы `A-Z`, `a-z`, `0-9`, `_` и `-`. |
| `TELEGRAM_BOT_TOKEN` | Для регистрации webhook | Токен бота от BotFather. Сервер во время обычной работы его не использует. |
| `TELEGRAM_WEBHOOK_URL` | Для регистрации webhook | Полный публичный HTTPS-адрес эндпоинта, например `https://example.com/telegram/webhook`. |
| `CURRENCY_BEACON_API_KEY` | Нет | API-ключ CurrencyBeacon. Если ключ не задан, используется только Frankfurter. |
| `PORT` | Нет | Порт HTTP-сервера. Значение по умолчанию — `3000`. |

Файл `.env` исключен из Git. Не добавляйте токены и API-ключи в репозиторий.

## Настройка Telegram webhook

Локальный сервер должен быть доступен Telegram по публичному HTTPS-адресу. Для разработки можно использовать HTTPS-туннель, а в рабочем окружении — домен с TLS-сертификатом.

Укажите в `.env` токен бота, секрет и полный URL маршрута:

```dotenv
TELEGRAM_BOT_TOKEN=123456:telegram-token
TELEGRAM_WEBHOOK_SECRET=replace-with-a-random-secret
TELEGRAM_WEBHOOK_URL=https://example.com/telegram/webhook
```

Зарегистрируйте webhook:

```bash
pnpm telegram:webhook:set
```

Скрипт проверяет, что URL валиден и использует HTTPS, а затем регистрирует только обновления типа `message`.

## Использование бота

Поддерживаются команды `/start` и `/help`, а также следующие форматы сообщений:

```text
EUR
EUR USD
100 EUR USD
100,50 EUR USD
```

Правила разбора:

- один код валюты означает конвертацию в USD;
- если сумма не указана, используется `1`;
- коды валют состоят из трех латинских букв и не зависят от регистра;
- допустимы точка или запятая в качестве десятичного разделителя;
- сумма должна быть положительной, не больше `1 000 000 000 000` и содержать не более шести знаков после разделителя;
- экспоненциальная запись и разделители тысяч не поддерживаются.

Бот отвечает только в приватных чатах. Обновления из групп и неподдерживаемые типы обновлений игнорируются.

## HTTP API

| Метод | Маршрут | Описание |
| --- | --- | --- |
| `GET` | `/health` | Liveness-проверка приложения (без проверки внешних провайдеров). |
| `POST` | `/telegram/webhook` | Прием обновлений Telegram. Требует секретный заголовок. |

Пример webhook-запроса для локальной проверки:

```bash
curl -X POST http://localhost:3000/telegram/webhook \
  -H "Content-Type: application/json" \
  -H "X-Telegram-Bot-Api-Secret-Token: replace-with-a-random-secret" \
  -d '{"update_id":1,"message":{"chat":{"id":123,"type":"private"},"text":"100 EUR USD"}}'
```

Ответ использует механизм Telegram webhook reply: объект содержит `method: "sendMessage"`, `chat_id` и текст сообщения. Невалидный секрет возвращает HTTP `401`; некорректные или неинтересующие приложение обновления подтверждаются ответом HTTP `200`, чтобы Telegram не отправлял их повторно.

## Источники курсов

При наличии `CURRENCY_BEACON_API_KEY` запрос сначала отправляется в CurrencyBeacon. При сетевой ошибке, тайм-ауте, ошибке ответа или неверной конфигурации приложение автоматически обращается к Frankfurter. Если ключ CurrencyBeacon отсутствует, Frankfurter используется сразу.

Оба провайдера имеют тайм-аут 3 секунды. Ошибка неподдерживаемой валюты от основного провайдера возвращается пользователю без fallback-запроса. В ответе бота указываются источник курса и, если провайдер передал эти данные, дата или время наблюдения.

## Архитектура

Проект разделен на слои, а получение курса подключается к бизнес-логике через порт `GetExchangeRate`:

```text
src/
├── app.ts                         # сборка зависимостей и запуск Fastify
├── application/
│   ├── ports/                     # интерфейсы провайдера и логгера
│   └── use-cases/                 # сценарий конвертации
├── config/                        # чтение переменных окружения
├── domain/                        # модели валют и доменные ошибки
├── infrastructure/
│   ├── currency-beacon/           # основной провайдер курсов
│   ├── exchange-rates/            # fallback-механизм
│   ├── frankfurter/               # резервный провайдер курсов
│   └── logging/                   # адаптер логгера Fastify
├── presentation/
│   ├── http/                      # HTTP-маршруты
│   └── telegram/                  # парсинг, обработка и форматирование
└── shared/                        # общие утилиты

scripts/
└── set-telegram-webhook.ts        # регистрация Telegram webhook
```

Основной поток запроса:

```text
Telegram → POST /telegram/webhook → проверка секрета → разбор сообщения
         → конвертация → CurrencyBeacon → Frankfurter при сбое → webhook reply
```

## Ограничения

- курсы зависят от доступности и набора валют внешних провайдеров;
- Frankfurter публикует дневные справочные курсы, поэтому данные могут не отражать изменения рынка в реальном времени;
- приложение не хранит историю запросов и не использует базу данных;
- Fastify по умолчанию слушает loopback-интерфейс; для прямого запуска в контейнере или на удаленном хосте потребуется reverse proxy либо настройка внешнего адреса прослушивания в приложении;
- автоматические тесты в репозитории пока не настроены.
